#  Juego-Asteroid

Un juego simple donde controlas una nave y interactuas con bolas de colores

## 🎮 Como Jugar

- **W, A, S, D**: Mover la nave
- La nave rota segun la direccion
- Las bolas rebotan con la nave y entre ellas
- La nave si va muy de prisa puede capturar la bola

## ⚙️ Controles del Panel

- **Slider Velocidad**: Cambia la velocidad de las bolas
- **Slider Tamaño**: Cambia el tamaño de las bolas  
- **Botón Añadir Pelota**: Añade una bola nueva con color aleatorio

## 🚀 Características
- Sistema de colisiones entre bolas
- Rebotes con la nave
- Panel de control integrado
- Fondo blanco limpio y imagen png
